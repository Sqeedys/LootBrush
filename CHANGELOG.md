# Changelog

## 0.1.0

- Bind held items to named weighted pools of loaded loot tables.
- Insert one real native loot roll into empty chests, double chests, or barrels.
- Preserve contents and pending vanilla loot; refuse overflow before insertion.
- Scatter items naturally with modest stack splitting.
- Add commands, persistent configuration, operator defaults, and optional LuckPerms permissions.
- Target Minecraft 26.3 with server-only Fabric installation.
